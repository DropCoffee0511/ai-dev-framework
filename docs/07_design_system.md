# 07 Design System

> **템플릿.** UI 일관성 규칙 (`MASTER_PROMPT.md` §11). 장식보다 업무 흐름과 정보 전달을 우선한다.

## 공통 용어

같은 기능은 같은 명칭과 위치를 쓴다. 저장/취소/삭제 같은 기본 행동 명칭을 임의로 바꾸지 않는다.

| 행동 | 표준 명칭 | 위치/형태 |
|---|---|---|
| 저장 | <...> | <...> |
| 취소 | <...> | <...> |
| 삭제 | <...> | <...> |

## 상태 표현

| 상태 | 표현 방식 | 색상 외 전달 수단(아이콘/텍스트) |
|---|---|---|
| <성공/오류/경고> | <...> | <...> |

색상만으로 상태를 전달하지 않는다.

## 오류 메시지 규칙

- 원인을 사용자가 이해할 수 있는 말로 표시한다.
- 오류 코드는 `docs/08_error_cases.md`의 ERR ID와 연결한다.
