# 06 Permissions

> **템플릿.** 권한(PERM) 정의. UI 숨김만으로는 권한 제어가 아니다. 서버/API에서도 검사해야 한다 (`MASTER_PROMPT.md` §9).
> 권한 모델 변경은 사용자 승인이 필요하다 (`MASTER_PROMPT.md` §21).

|---|---|---|---|
