## 검토 체크리스트 (REQ마다 해당 여부 확인)

`MASTER_PROMPT.md` §5.8 / §5.10 기준. 해당하지 않으면 "해당 없음"과 이유를 적는다.

- [ ] 필수값 누락
- [ ] 잘못된 형식
- [ ] 권한 없는 사용자
- [ ] 존재하지 않는 데이터 / 삭제된 데이터 참조
- [ ] 중복 요청, 중복 제출, 재시도에 따른 중복 생성
- [ ] 동시 수정, 오래된 화면 상태에서 저장
- [ ] 네트워크/서버 오류
- [ ] 세션 만료
- [ ] 승인 후 수정 시도 (상태가 있는 기능)
- [ ] 예상보다 큰 입력, 잘못된 파일 업로드
